DevOps Tools with AWS

  • Git/GitHub

    Git is a distributed version control system, and GitHub is a platform for hosting and collaborating on Git repositories.

  • Jenkins

    Jenkins automates building, testing, and deploying software using CI/CD pipelines.

  • Docker

    Docker allows packaging applications into containers for consistent environments across development and production.

  • Kubernetes

    Kubernetes orchestrates containerized applications, automating deployment, scaling, and management.

  • Ansible

    Ansible simplifies configuration management and automation of servers and applications.

  • Prometheus & Grafana

    Prometheus monitors metrics, while Grafana provides visualization dashboards for observability.

  • Terraform

    Terraform manages cloud infrastructure as code, making provisioning and scaling consistent and repeatable.

  • SonarQube

    SonarQube analyzes code quality and identifies bugs, vulnerabilities, and code smells.

  • Nexus

    Nexus is a repository manager to store and manage binary artifacts for software development.

  • AWS

    Amazon Web Services (AWS) provides cloud computing platforms and services for building scalable and reliable applications.
